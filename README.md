# Task Management System - Backend

Yeh ek simple backend API hai jo Node.js, Express aur MongoDB use karke bani hai.  
Isme user register/login kar sakta hai aur apne tasks create, read, update, delete kar sakta hai.

Main yeh project internship ke Task 2 ke liye bana raha hoon.

---

## Features

- User register aur login (JWT authentication)
- Password bcrypt se hash hota hai, plain text save nahi hota
- Har user sirf apne tasks dekh sakta hai
- Task create, read, update, delete (CRUD)
- Role based access (user / admin)
- Protected routes middleware se secure hain
- CORS enabled hai frontend ke liye

---

## Tech Stack

- Node.js
- Express.js
- MongoDB + Mongoose
- JWT (jsonwebtoken)
- bcryptjs
- dotenv
- cors
